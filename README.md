# けれけれ記録

けれけれの放送回を記録・検索する、モバイル対応のWebアプリです。

- 放送一覧／表表示の切り替え
- 放送回の追加・編集
- テーマ・コーナー・曲・名言検索
- 表の列順変更と並び替え
- 文字サイズ・行の高さ・折り返し調整
- JSONバックアップ・復元
- HTTPS環境でオフラインキャッシュ

記録はブラウザのlocalStorageに保存されます。端末やブラウザを変更する場合は、バックアップを取り復元してください。radiko取り込みはURL/説明文の簡易解析で、全話自動取得機能ではありません。
